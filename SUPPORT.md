# Support

## Before Opening An Issue

1. Confirm you installed the latest release from this repository.
2. Verify the download using [SHA-256 and platform checks](docs/VERIFY.md).
3. Restart AiRC and reproduce the issue once.
4. Remove API keys, access tokens, passwords, private URLs, and personal data from all diagnostics.

## Open An Issue

Use the issue templates for:

- installation or launch failures
- model or provider behavior
- extensions, automations, browser, or computer-use behavior
- user interface problems
- feature requests

Include the AiRC version, operating system version, processor architecture, provider type, expected behavior, observed behavior, and minimal reproduction steps.

## Security Issues

Do not file vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).
