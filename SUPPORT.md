# Support

AiRC Orchestration is in active Beta development. No public installer has been published yet; issues are currently most useful when they clearly identify the authorized Beta build being tested.

## Before Opening An Issue

1. Record the exact AiRC build or version, operating system version, and processor architecture.
2. If you installed a build from this repository's Releases page, verify it using [SHA-256 and platform checks](docs/VERIFY.md).
3. Restart AiRC and reproduce the issue once.
4. Remove API keys, access tokens, passwords, private URLs, local file paths, project content, and personal data from all diagnostics.

## Open An Issue

Use the issue templates for:

- installation or launch failures
- model or provider behavior
- tools, extensions, skills, apps, or recipes
- goals, plans, Orchestrator session coordination, subagents, or automations
- browser or computer-control behavior where enabled
- user interface problems
- feature requests

Include the AiRC build, operating system version, processor architecture, provider type, expected behavior, observed behavior, and minimal reproduction steps.

## Security Issues

Do not file vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).
