# Public Demo Asset Provenance

The visuals in this directory were prepared specifically for public product presentation. They are captures of the real AiRC Orchestration Beta interface, not mockups.

## AiRC Whisper Browser Workflow

- **User prompt:** `use the in app browser and open the public AiRC Whisper GitHub page then summarize the app`
- **Selected model:** `muse-glimmer:30b-q4_K_M-dflash`
- **Demo destination:** the public [`AiRC-ai/AiRC-Whisper`](https://github.com/AiRC-ai/AiRC-Whisper) repository
- **Captured:** August 11, 2026
- **Observed outcome:** AiRC opened the repository in its integrated browser and produced a product, architecture, build, and licensing summary alongside the live public page
- **Capture isolation:** a dedicated AiRC task and window with the project sidebar collapsed
- **Privacy review:** every published frame was inspected before export; no private project list, credentials, account data, private source, or private local path appears
- **Export:** the public GIF and three still frames are derived from the recorded AiRC window without fabricated interface elements

The visible GitHub interface and marks remain subject to GitHub's terms and trademark guidelines. AiRC Whisper source is MIT licensed; AiRC branding and screenshots retain the separate rights described in that repository's `TRADEMARKS.md`.
