# Security Policy

## Report A Vulnerability

Do not report security vulnerabilities in public issues, discussions, or pull requests.

Send a private report to [security@airc.ai](mailto:security@airc.ai). Include:

- affected AiRC version and operating system
- clear reproduction steps
- expected and observed behavior
- impact and any known workarounds
- logs or screenshots with credentials and personal data removed

Do not include production credentials or unredacted customer data. If a safe proof requires sensitive material, describe what you have first and wait for secure-transfer instructions.

## Scope

Security reports may cover the distributed desktop application, installer behavior, update behavior, provider credential handling, browser isolation, tool execution boundaries, extensions, automations, and local or remote model connections.

Third-party services and model providers remain subject to their own security policies.

## Supported Releases

Security fixes target the latest published Beta release. Reports against authorized private test builds are also accepted when they identify the exact build. Users may be asked to update before further diagnosis when an issue affects an older release.
