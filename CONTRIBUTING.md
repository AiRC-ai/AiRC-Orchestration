# Contributing

This repository distributes compiled AiRC Orchestration releases and tracks public product feedback. It does not contain the application source code.

## Useful Contributions

- reproducible bug reports
- focused feature requests
- corrections to installation, verification, or support documentation
- platform compatibility findings with exact operating system and architecture details

Do not submit credentials, private logs, customer data, proprietary source, generated build directories, or application binaries in a pull request.

For vulnerabilities, use the private process in [SECURITY.md](SECURITY.md).
